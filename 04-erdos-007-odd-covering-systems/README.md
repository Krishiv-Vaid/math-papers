## The problem

Is there a **distinct covering system**, i.e. finitely many congruence classes $a_i \bmod n_i$ with distinct moduli $1<n_1<\dots<n_k$ whose union is $\mathbb Z$, **in which every modulus is odd**?

The odd *and squarefree* version is impossible (Balister–Bollobás–Morris–Sahasrabudhe–Tiba, *Invent. Math.* 2022).
